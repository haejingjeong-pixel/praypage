Primary action button for 마음약국 — warm coral by default, prescription-blue for the result-screen CTA.

```jsx
<Button tone="coral" size="lg">말씀 처방받기</Button>
<Button tone="rx" icon={<Icon name="book-open" size={18} color="#F7FAFF" />}>말씀광장에서 '믿음' 열어보기</Button>
<Button tone="outline" icon={<Icon name="download" size={18} />}>이미지로 저장하기</Button>
```

Tones: `coral` (primary), `rx` (blue CTA), `outline` (white card), `ghost`. Sizes `sm|md|lg`. Pass `block` for full-width, `icon` for a leading glyph.
