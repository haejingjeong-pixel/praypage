Thin line-icon wrapper around Lucide — use for every glyph in the 마음약국 system (mood icons, prescription field icons, button icons).

```jsx
<Icon name="heart-crack" size={22} color="var(--mood-broken-ink)" />
<Button tone="rx" icon={<Icon name="book-open" size={18} color="#F7FAFF" />}>말씀광장에서 열어보기</Button>
```

Requires the Lucide UMD script on the page. Common names: `heart-crack`, `waves`, `user`, `hourglass`, `heart-handshake`, `church`, `sprout`, `sunrise` (moods); `calendar`, `heart-pulse`, `book-open`, `pill`, `triangle-alert`, `star`, `plus` (prescription). `stroke` defaults to 1.6.
